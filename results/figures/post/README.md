# Post figures (agent V)

Regenerate: `source .venv/bin/activate && python scripts/make_post_figures.py [--only figB_exchange_rate ...]`.
Each figure: `<name>.png` (2x, 1600 px wide, shown at ~800 px), `<name>.svg`, `data/<name>.csv` (plotted values plus a `source` column).
Colours are fixed across figures: GENCO orange, pre-contingency state purple, flat start grey (square marker), DC blue, plain GENCO-Delta magenta, residual GENCO-Delta green.
Draft numbering below follows the file letters (A = Fig. 1 ... G = Fig. 7); renumber to the post order.

- **figA_workflow** (`data/figA_workflow.csv`, node list only). Fig. 1. Verified screening workflow: after an outage, either the pre-contingency state or the GENCO prediction starts k float64 Newton steps with exact admittances; a calibrated bound c·||dx||^2 on every monitored element (branch loading, PQ-bus voltage) decides between accepting the screen and escalating to full Newton.
- **figB_exchange_rate** (`data/figB_exchange_rate.csv`). Fig. 2. Newton iterations to 1e-2, 1e-4 and 1e-6 MW from flat, DC, pre-contingency and GENCO starts (a), and the paired GENCO minus pre-contingency difference (b), with 95% cluster-bootstrap CIs over load scenarios. IEEE 118 Base (released seed 0, paper-test set, n = 638, 29 load scenarios), GOC 500 Base (n = 638, 29 loads), GOC 2000 Small (held-out, n = 879, 40 loads); open dots: IEEE 118 seeds 1 and 42 on their own splits. Difference at 1e-6 MW: -0.73, -0.04, +0.22.
- **figC_equal_cost** (`data/figC_equal_cost.csv`). Fig. 3. Missed violating elements (% of violating elements, log scale) against LU factorizations per contingency for GENCO + k and pre-contingency + k Newton steps (k = 1, 2, 3; GENCO alone at 0), and the sequential-verification policies (conformal alpha = 0.10, calibrated on 100 load scenarios of calib N-1, evaluated unchanged). IEEE 118 Base seed 0, four stress sets N-1/2/3/5 (2,200 / 2,199 / 2,199 / 2,194 contingencies, 100 load scenarios each; tau = 1.01, 1 mV). Hollow markers are zero-miss cells, drawn at their one-sided 95% Clopper-Pearson upper bound. k = 1, 2 agree with `results/exp02/big118_ladder.csv` (asserted); k = 3 is recomputed from the stored per-element predictions.
- **figD_factor_reuse_breakeven** (`data/figD_factor_reuse_breakeven.csv`). Fig. 4. (a) Triangular solves saved by a GENCO start against a pre-contingency start under full Newton, outage-compensated chord and fast-decoupled solvers to 1e-4 MW (95% CI): IEEE 118 paper set from `results/exp07/summary_paired_genco_vs_base.csv`, GOC 500 Base parsed from `results/notes/batch3_H.md` section 2.3 (rounded to 1%). (b) Break-even inference time (larger of the 1e-2 and 1e-4 MW values) against measured GENCO inference per scenario on an M4 (filled: batch 16, open: batch 1; `results/runtime/*.json`). GPU row is a placeholder: the function reads `results/colab/**/genco_gpu_timing.csv` when present (columns per `notebooks/colab_gpu_timing.ipynb`) and then draws it automatically.
- **figE_slack** (`data/figE_slack.csv`). Fig. 5. Median over test contingencies of the max power mismatch, as reported (GENCO's own slack voltage) and physical (true slack setpoint), with 95% cluster-bootstrap CIs; ratios 36, 39, 32, 60, 19, 26 (198 scenarios) and 20 (879 scenarios). Source `results/exp06/summary.csv`; IEEE 14/30/57/118 Base and GOC 500 Base on 638 paper-test scenarios (631 for IEEE 57).
- **figF_genco_delta** (`data/figF_genco_delta.csv`). Fig. 6. IEEE 118 Base: median state error (a) and Newton iterations to 1e-2 MW (b), mean and SD over init seeds 0/1/42 (n = 3; plain Delta n = 2), for released, control, slack-aware, plain Delta (vm,va and vm,va,flows) and residual Delta (lr 1e-4 and 3e-4) on the paper set and stress N-1/2/3/5 (about 660 contingencies each; paper set is each seed's own split: 638 / 814 / 616). Plain-Delta seed 42 diverged and is excluded from the mean and shown as a cross (its evaluation is off scale or crashed, see CSV columns `seed42_evaluation`). Purple bars: pre-contingency state. Source `results/genco_delta/residual_summary_runs.csv`. Any `residual_nk_*` arm that appears there is added automatically (none present at time of writing).
- **figG_hero** (`data/figG_hero.csv`). Fig. 7 (optional). One IEEE 118 N-2 contingency (stress N-2 test scenario 476, chosen as the median-mismatch case among those needing 2 / 3 / 4 Newton iterations from GENCO / pre-contingency / flat to 1e-6 MW): max mismatch after each of GENCO's 12 layers, then Newton steps in float64 from GENCO's output, the pre-contingency state and a flat start. This is the only figure that recomputes anything (one forward pass and three short Newton runs); the result is cached in the CSV, `--recompute` redoes it.
